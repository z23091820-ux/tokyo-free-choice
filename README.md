# 東京自由行多日旅程管理版 V8

新增功能：
- 每個已安排景點可填寫、修改或刪除備註
- 備註會依「旅程日期＋景點」分別保存
- 第一天可填寫去程航班編號、日期時間及備註
- 最後一天可填寫回程航班編號、日期時間及備註
- 航班資料會保留在該段旅程歷史紀錄中
- 保留 V7 的多日旅程、每日景點、Google Maps 導航與歷史旅程功能

- README.md
