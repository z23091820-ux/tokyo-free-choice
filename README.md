# 東京自由行｜雙模式家庭共享版 V15

本版保留兩種模式：

## 匿名模式
- 從 LINE 點網址即可直接使用
- 不需要 Google、Email 或密碼
- 建立或輸入 6 位家庭分享碼即可共用

## Google 帳號模式
- 保留 Google 登入／綁定功能
- 屬於選用功能
- 建議在 Safari、Chrome 或電腦瀏覽器操作
- LINE 內建瀏覽器若無法完成 Google 登入，不影響匿名分享功能

## 資料保護
- 延續 V14 安全更新機制
- 更新前自動備份
- 本機與雲端資料採合併
- 保留景點、旅程、航班、備註及分享資料
- 可下載與匯入 JSON 備份
