# 多城市家庭旅程管理 V20.7－既有景點區域初步預選版

## 新增
- 既有景點會先依名稱與既有資料進行初步區域預選
- 原本已有明確區域的景點完全保留
- 僅針對「Google Maps 東京清單、未標記、自訂、待確認」等籠統區域處理
- 無法合理判斷的景點標記為「待確認」
- 找景點頁新增「待確認」按鈕，方便集中人工整理
- 初步預選只執行一次，不會覆蓋日後手動修改結果
- 所有區域仍可由家庭成員自行新增、重新命名、刪除與調整

## 初步分類範例
- 淺草寺、雷門、晴空塔 → 淺草／押上
- 上野公園、阿美橫町 → 上野／谷中
- 東京站、丸之內、日本橋 → 東京站／日本橋
- 銀座、築地 → 銀座／築地
- 新宿御苑、東京都廳 → 新宿
- 澀谷、原宿、表參道 → 澀谷／原宿／表參道
- 台場、豐洲 → 台場／豐洲
- 迪士尼 → 舞濱／迪士尼
