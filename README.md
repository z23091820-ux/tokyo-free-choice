# 東京自由行｜友善操作版 V6

本版重新檢視並改善：

- 手機優先、長輩友善的大按鈕與清楚導覽
- 可連續輸入的搜尋框與清除搜尋按鈕
- 資料來源篩選：我的 Google 清單／精選景點／自行新增
- 分類收合，減少畫面擁擠
- 隱藏同名重複地點
- 景點可「查看地點」與「大眾運輸導航」
- 想去清單可手動調整順序
- 行程可設定出發時間
- 手動新增後可刪除
- 文字放大模式
- 更新 Service Worker，降低舊快取問題

## GitHub 更新方式

請將整個資料夾內的檔案上傳並覆蓋原儲存庫檔案，尤其是：

- index.html
- app.js
- styles.css
- service-worker.js
- manifest.json
