# 多城市家庭旅程管理 V20

## 核心資料邏輯
- 景點只建立一次
- 同一景點可加入多個目的地清單與多個旅程
- 每一趟旅程有獨立的想去清單、每日安排、備註、預約與交通資料
- 不同旅程引用同一景點時，彼此安排互不影響

## 找景點
- 可切換或自行新增目的地
- 關鍵字搜尋
- 景點分類
- 室內／室外
- 步行程度
- 查看地圖、導航
- 加入目前想去清單
- 直接加入指定旅程

## 想去清單
- 依目的地分類
- 依旅程分類
- 同一景點可同時存在多個旅程清單

## 旅程
- 旅程名稱、目的地、日期、狀態、備註
- 狀態：規劃中、即將出發、旅途中、已完成、已封存
- 航班資料
- 每日行程
- 旅程專屬想去清單

## 每日安排
- 調整順序
- 移動到其他日期
- 導航
- 行程專屬備註
- 預約時間
- 交通方式
- 票券／訂位資訊

## 家庭共享
- 固定分享碼，只建立一次
- 更新版本後自動沿用
- 匿名模式可從 LINE 直接使用
- Google 登入保留為選用
- 同一家庭以 Firestore 雲端資料為共同版本

## 資料安全
- 更新前自動備份
- 保留既有 LocalStorage Key、家庭 ID 與分享碼
- 舊資料自動轉換
- 可下載與匯入 JSON 備份
