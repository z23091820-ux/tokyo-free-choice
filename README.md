# 多城市家庭旅程管理 V20.5－自訂區域管理版

- 區域名稱不固定
- 每個目的地可自行新增、重新命名、刪除區域
- 標記景點時可選既有區域，也可直接輸入新區域
- 新區域會自動加入該目的地清單
- 區域清單與景點標記同步給所有家庭成員
- 原本區域、固定分享碼、家庭 ID、旅程、想去、航班與備註均保留
