# 東京自由選景點 Web App

這是可直接部署的靜態 Web App。

## 本機使用
直接開啟 `index.html` 即可操作；離線安裝功能需透過網站伺服器或 HTTPS 開啟。

## 可部署平台
- GitHub Pages
- Netlify
- Vercel
- 公司 IIS / Nginx / Apache

## 目前功能
- 手機、平板、電腦響應式介面
- 景點搜尋與分類
- 自行新增景點
- 想去清單
- 依區域整理建議順序
- Google Maps 搜尋
- 瀏覽器本機資料保存
- PWA 安裝與離線快取設定

## 尚未串接

- 家人多人同步
- GPS、即時交通與天氣
